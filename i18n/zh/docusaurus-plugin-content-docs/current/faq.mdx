# 常见问题

这是 SideStore 的常见问题列表。这里列出了我们在开发 SideStore 过程中常遇到的问题，以及一些可能对不同类型的用户或有问题的用户有帮助的问题。

## 什么是 SideStore?

SideStore 是一款 iOS 应用，它仅使用你的 Apple ID 即可将应用侧载到你的 iOS 设备上。SideStore 会用你的个人开发证书对应用重新签名，然后使用一个[specially designed VPN](https://apps.apple.com/us/app/localdevvpn/id6755608044)来欺骗 iOS 使其安装这些应用。SideStore 会定期在后台“刷新”你的应用，以防它们的正常 7 天开发期限过期。

SideStore 的目标是提供无束缚的侧载体验。它是 [AltStore](https://github.com/rileytestut/AltStore) 的社区驱动分支，并且已经实现了社区最常要求的一些功能。你只需要在安装过程中使用一次电脑。

（欢迎贡献！🙂）

### SideStore 有哪些限制？

如果使用免费 Apple 账户，SideStore 一次只能安装 3 个应用（包括它自身）。此外，每周只能安装 10 个不同的应用。（称为 App ID。）

### 我可以激活 JIT 吗？

对于使用 iOS/iPadOS 16 或更低版本的用户，你可以在 SideStore 的 'My Apps'（我的应用）页面上按住你的应用并选择 'Enable JIT'（启用 JIT）来直接激活 JIT。

使用 iOS 或 iPadOS 17.4 或更高版本的用户可以使用诸如 SideStore 0.6.2 或 StikDebug（原 StikJIT）之类的解决方案。请参阅[Advanced](advanced/jit)教程部分。

### SideStore 什么时候发布？

SideStore 目前还没有发布日期，但已处于公开测试阶段。

### 你现在可以侧载应用吗？

是的，可以，就像 AltStore 一样！

### SideStore 有 AltStore (beta) 的功能吗？

我们确实实现了 AltStore (beta) 的功能，但它们不一定是最新的。我们尽量保持更新，或者在必要时以我们自己的方式实现。

### 开启 VPN 会消耗我的电池电量吗？

不会，因为它只连接到你自己的设备。不使用远程服务器，意味着没有外部连接，也就意味着不会额外消耗电池。

### VPN 会跟踪我吗？

不会，因为没有使用远程服务器。

### 我可以签署超过 3 个应用使其变为活跃状态吗？

通常情况下，不能，因为那是 iOS 和开发者账户的限制。Apple 只允许使用免费 Apple 开发者账户安装 3 个应用。

要移除这个限制（并且还能获得 365 天的有效期），你可以每年支付 99 美元购买 Apple 开发者账户。

或者，你可以使用 LiveContainer，或者对于 iOS 18 db5/18.0.1 及更低版本，你可以利用 SparseRestore 漏洞来绕过 3 个应用的限制。（不会绕过 10 个 app-id 的限制。）

使用此方法的教程可以[here](advanced/alternative)找到。

### 我遇到了问题、错误,或者想请求某项功能或生活质量改进

请先查看[common issues](troubleshooting/common-issues)和现有的 GitHub issues，如果找不到你的问题，请在我们的 GitHub 页面上创建一个新的 GitHub issue 来提交错误报告或功能请求（请带上合适的标签）！

### 我是一名开发者，这对我有什么影响？

你的应用不需要任何修改即可与 SideStore 一起工作！

### 我需要安装 AltStore 才能安装 SideStore 吗？

不需要，你可以通过我们[guide](installation/prerequisites)直接侧载 SideStore！

### 作为用户，我登录 SideStore 时遇到了问题。我收到了一个错误。

可能导致这种情况的原因有很多，但最常见的问题是 Anisette 服务器临时宕机。你目前可以在设备上 SideStore 的“Anisette URL”下的 Settings（设置）应用中更改 Anisette 服务器。

### SideStore 会有一家商店吗？

我们目前有社区源！源 URL：https://community-apps.sidestore.io/sidecommunity.json

我们还有一个名为 [SideStore Connect](https://connect.sidestore.io) 的服务，它允许开发者发布自己的应用。

### 为什么我的应用有一个名为“pacer test”的更新？

这是一个测试更新，用于检查主要版本之间是否存在问题，正常使用中不应该看到它。如果你在发布后看到这个问题，那么请重新安装 SideStore 或将其作为 bug 报告。

### 为什么我基于 JIT 的应用不能自动激活 JIT？

我们目前没有自动激活 JIT 的方法，而且如果我们要做，你会需要开启 LocalDevVPN。另外，你也可以使用 StikDebug。

### SideStore 有 iPadOS 界面吗？

我们当然有！

### 我看到我的账户里添加了一台 iMac 或 MacBook Pro。这安全吗，它是真实的 Mac 吗？

这些 Mac 不是真实的，它们是由 Anisette 服务器自动生成以协助登录的。也没有任何私人数据发送到 Anisette 服务器，因为服务器提供的数据只在 SideStore 内使用。

### 为什么我使用 SideStore 时账户会被锁定？

已知许多用户使用的旧版 Anisette 服务器会导致 Apple ID 被锁定。请使用官方 Anisette 服务器之一，或自行托管 [anisette-v3-server](advanced/anisette)。

### 我可以转移我的 AltStore/Sideloadly 应用吗？

可以，只要不删除设备上的原始应用即可。进入 SideStore 并侧载相同或更新版本的 IPA，它应该会添加到你在 SideStore 内的应用列表中，并且你的数据仍然完好无损。

### 为什么我登录后第一件事就是刷新 SideStore？

这是因为 iloader 和其他程序经常使用它们自己的应用 groupID 来侧载 SideStore，而我们使用我们自己的。刷新 SideStore 可以确保它被更改为我们的，这会使具有过时 groupID 的应用消失。干净安装后，最好在刷新 SideStore 之前不要侧载任何东西。

### SideStore 支持 OTA 更新吗？

支持！当更新按钮出现时，只需点击它即可！

### 我想测试一个 SideStore 版本，并且在切换到测试版本时想让我的数据保留。我应该删除我的应用还是通过 SideStore 侧载测试版本？

你可以通过 SideStore 或 iloader 侧载一个夜间版 SideStore，你的数据应该会保留，或者启用测试版更新并在 Settings（设置）中选择“nightly”。我们无法保证在测试非官方或夜间版本时你的数据能成功转移。

### 目前已知问题

如果你目前遇到问题，并且想知道我们是否已经知晓它们，请查看我们的 GitHub issue 页面和故障排除页面，那里列出了已知问题以及缓解你可能遇到的一些问题的方法。此列表中的某些问题可能不在其中已知，但存在于 GitHub issues 部分。[GitHub](https://github.com/SideStore/SideStore/issues/490)，[troubleshooting](/docs/troubleshooting/)。

如果你有任何不在此列表中的问题。只需创建一个 GitHub issue 或[join our discord.](https://dis.sidestore.io/)
