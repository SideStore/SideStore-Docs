  <TabItem value="win" label="Windows">

  </TabItem>
  <TabItem value="linux" label="Linux (Altcon)">
    开始之前，请确保已安装 usbmuxd。
   1. 在 Linux 终端中运行 `sudo apt install -y usbmuxd`，确保你已安装并更新了 usbmuxd。
   2. 在你的机器上安装 Docker 或 Podman。
   3. 插入你的备用 iPhone、iPad 或 iPod touch。如果收到提示，请选择 “Trust” 并输入你的密码。
   4. 现在，使用以下命令通过 Docker 或 Podman 运行 Altcon（可能需要 `sudo`）：

   Docker 设置：
   ```bash
   docker run --rm -it -v ${PWD}/:/mnt/ -v /var/run/usbmuxd:/var/run/usbmuxd -v /var/lib/lockdown:/tmp/lockdown ghcr.io/sidestore/altcon
   ```

   Podman 设置：
   ```bash
   podman run --rm -it -v ${PWD}/:/mnt/ -v /var/run/usbmuxd:/var/run/usbmuxd -v /var/lib/lockdown:/tmp/lockdown ghcr.io/sidestore/altcon
   ```

   5. Altcon 将与你的设备配对。当你收到另一个提示时，请再次选择 “trust” 并输入你的密码。
  </TabItem>
</Tabs>

#### 使用 AltServer 在同一账户上为多个设备设置 SideStore（仅适用于 macOS/Windows）
步骤：
1. 使用上述说明在 macOS/Windows 上设置 AltServer
2. 使用 AltServer 在一台设备上安装 AltStore
3. 在 AltStore 中登录 Apple 账户
4. 导出证书
5. 删除 AltStore

然后对每台设备执行以下操作：
1. 使用同一个 Apple 账户通过 AltServer 安装 SideStore（点击 AltServer -> Install IPA -> 选择 SideStore.ipa 时按住 [Option/Mac、Shift/Windows]）
2. 导入证书
3. 在 SideStore 中登录 Apple 账户（我们需要在导入证书后登录，否则在未撤销 AltStore 证书的情况下，它将不允许你登录）
4. 旁加载

当旧证书过期时：
1. SideStore 将提示在一台设备上重新安装自身
2. 重新安装后，导出证书

然后对每台其他设备执行以下操作：
1. 导入新证书
2. 从 SideStore 中旁加载 SideStore IPA

## VPN
### WireGuard
:::note
SideStore WireGuard VPN **仅适用于 0.3.1～0.6.1 之间，以及 0.6.3-nightly.4e6756d 及之后的 SideStore 版本**，如果你有替代方案（LocalDevVPN），则不推荐使用它。如果你的版本不在这些范围内且不起作用，**请不要为此寻求支持**。
:::

SideStore 利用设备上的 WireGuard VPN，使 SideStore 能够与内部服务通信。

1. 从 [Apple App Store](https://apps.apple.com/app/wireguard/id1441195209) 下载 WireGuard 应用。
2. 同时，下载在[这里](https://github.com/SideStore/SideStore/releases/download/0.3.1/SideStore.conf)找到的 WireGuard 配置。
3. 打开 WireGuard，并按下 “Add a Tunnel” 或 “+” 按钮。
4. 选择 “Create from file or archive”，并选择 SideStore.conf 文件。
5. 你的设备可能会询问是否要 “Allow VPN Configurations”，请选择 “Allow” 并进行身份验证。
6. 打开 SideStore VPN 选项的开关。

只要你使用 SideStore，就必须开启此 VPN，因为没有它，大部分功能将无法工作。

#### 安装说明

  <TabItem value="win" label="Windows">

   2. 下载 [idevice pair for Windows](https://github.com/jkcoxson/idevice_pair/releases/latest/download/idevice_pair--windows-x86_64.exe)，并将其移动到你能记住的位置。
  </TabItem>
  <TabItem value="linux" label="Linux">
   1. 在 Linux 终端中运行 `sudo apt install -y usbmuxd`，确保你的机器上已安装 usbmuxd。
   2. 下载与你的电脑架构相对应的适用于 Linux 的 idevice_pair 版本（[x86_64](https://github.com/jkcoxson/idevice_pair/releases/latest/download/idevice_pair--linux-x86_64.AppImage)或 [AArch64](https://github.com/jkcoxson/idevice_pair/releases/latest/download/idevice_pair--linux-aarch64.AppImage)）。将其移动到你能记住的位置，并使其可执行。
  </TabItem>
</Tabs>

#### 配对说明

1. 用数据线将你的备用设备连接到电脑。如果出现提示，请选择 `trust` 并输入你的密码。
2. 解锁你的设备，然后打开 `idevice pair`，并在下拉菜单中选择你的设备。
3. 确保你的设备已解锁并打开到主屏幕，然后选择 `load`。如果你的设备上出现提示，请点按 `trust`。你的配对文件应该会出现。
4. 确保你的设备仍处于主屏幕，然后向下滚动并选择 “SideStore” 下方的 `install`。应该会以绿色显示 `Success`。

### JitterbugPair
JitterbugPair（*不是* Jitterbug 应用）使我们能够为 SideStore 等程序创建配对文件，以便远程与你的设备通信。这是使用 SideStore 所必需的，否则它将无法运行。

下载适用于 [Windows（64 位）](https://github.com/osy/Jitterbug/releases/download/v1.3.1/jitterbugpair-win64.zip)、[macOS](https://github.com/osy/Jitterbug/releases/download/v1.3.1/jitterbugpair-macos.zip) 或 [Linux](https://github.com/osy/Jitterbug/releases/download/v1.3.1/jitterbugpair-linux.zip) 的 JitterbugPair。

#### 配对说明

:::tip

根据你的方法，在传输你的 .mobiledevicepariring 文件时，文件扩展名可能会改变（通常会变成 .txt 或去掉 “ing” 结尾）。始终建议在传输配对文件之前先将其压缩为 zip 文件。SideStore 只接受 .mobiledevicepairing 文件（旧版本中为 .plist 文件）。
:::

## SideStore 漏洞
### SparseRestore（3 应用限制）
:::note
SparseRestore “Bypass 3 app limit”漏洞**仅适用于 17.0 到 18.1 beta 4（不含 17.7.1）之间的 iOS/iPadOS 版本**。如果你的版本不在这些范围内且不起作用，**请不要为此寻求支持**。
:::

#### 前置条件
* 一台运行 SparseRestore 漏洞所支持版本的 iPhone 或 iPad（见上方注释）。
* 至少 1 个空闲的应用位。
* SideStore 0.5.9 或更高版本。你可以在[这里](https://github.com/SideStore/SideStore/releases)找到最新版本。
* 要执行此漏洞，你的 iPhone 或 iPad 在该过程中必须关闭 **Find My**。否则它将无法工作。以下是关闭方法：
  - 打开设置应用。
  - 点按顶部的你的姓名。
  - 点按 Find My。
  - 点按 Find My iPhone/iPad。
  - 关闭 Find My iPhone/iPad。
  - 可能需要输入你的 Apple 账户密码进行确认。
  
  > **注意：**你仍然可能无法关闭 Find My，因为开启“失窃设备保护”（Stolen Device Protection）可能会阻止你将其关闭。请先关闭失窃设备保护，再尝试关闭 Find My。

#### 步骤
1. 安装 SparseBox。这可以通过多种方法完成，但出于本说明的目的，请使用 SideStore 安装它。最新版本可在[这里](https://github.com/khanhduytran0/SparseBox/releases/download/0.0.1/com.kdt.sparsebox_0.0.1.ipa)找到。

2. 在 SideStore 中勾选 “Disable App Limit”，并确保 SideStore 已**关闭**（而非在后台运行），然后打开 SparseBox。

3. 启用 LocalDevVPN，选择你的配对文件并点按 “Bypass 3-app limit”。这应该会弹出日志输出。等待它显示 `idevicebackup2 exited with code -18` 或 `idevicebackup2 exited with code 2`，然后关闭应用。无需点击 apply。

4. 重新打开 SideStore，并在 SideStore 设置中向下滚动。按 “clear cache”，这将使 SideStore 能够识别该漏洞。

5. 测试该漏洞是否已生效（根据你有多少个空闲位，你可能需要安装不止一个应用来测试）。如果它抛出有关限制的错误，请重新打开 SideStore 或重试该漏洞。如果它成功安装了应用，恭喜你。你现在可以同时安装超过 3 个应用了。

#### 注意事项
由于某些限制，每额外旁加载 3 个应用，就必须重新执行一次此漏洞。

如果你出于其他目的需要 Find My，现在可以重新打开它。但是，如果你想安装或刷新更多应用，则需要再次将其关闭。

## Lara（3 应用限制绕过）

:::note
“Lara”绕过使用了 **Darksword 漏洞**，该漏洞仅适用于 **iOS 17.0～iOS 18.7.1 和 iOS 26.0.x**，**M5 和 A19 设备**除外。
它也被确认可在 **iOS 16.7.2** 上运行。

如果你不在受支持的版本上，**请不要寻求支持**。
:::

要使用此方法，请确保你运行的是最新的 **SideStore Nightly**，然后安装 **Lara**：
https://github.com/rooootdev/lara/releases/
（Lara 也可以在 LiveContainer 内部运行。）

### 步骤

1. 打开 Lara 并点按 **Run Exploit**

3. 点按 **Initialize System**

5. 前往 **Apps**
6. 选择 **3-App Bypass**
7. 点按 **Bypass**

:::warning
在完成所有步骤之前，**不要**从应用切换器中关闭 Lara。
:::

8. 打开 SideStore，并像往常一样安装你的 IPA
9. 完成

:::note
这**不会**增加 10 个应用的 Apple ID 限制。
:::

每新旁加载一个应用，你**必须**重复此过程。
