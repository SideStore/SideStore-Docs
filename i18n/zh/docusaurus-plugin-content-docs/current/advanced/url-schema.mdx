# URL Schema

以下是可用于与 SideStore 交互的不同 URL Scheme 列表。这些方案非常有用，因为它们允许开发者简单地在他们的社交媒体或网站上放置一个一键链接，然后 iOS 将直接在 SideStore 中打开该链接，执行所指定的操作。

目前可以使用 URL Scheme 执行的操作仅限于安装应用和源，但未来将扩展为接收多个输入并执行各种其他任务。

## 安装远程托管的应用

```
sidestore://install?url=[download url]
```

## 添加 AltSource

```
sidestore://source?url=[source url]
```
