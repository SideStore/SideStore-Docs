:::note
من غير المرجح أن يؤدي استخدام أي إصدار من SideStore بعد إصدار 0.4.0 إلى قفل حسابك؛ إذ تمت في ذلك الإصدار إضافة دعم خوادم anisette النسخة الثالة.

وبناءً على ذلك، **يُوصى بشدة** باستخدام خادم نسخة ثالثة للاستخدام العادي لـ SideStore، إذا كان إصدارك يدعم ذلك.
:::

بيانات "Anisette" هي معلومات تُستخدم في عملية توقيع التطبيقات، وتتطلب التوليد في كل مرة تقوم فيها بتثبيت التطبيقات أو تنشيطها. يحصل تطبيق SideStore على هذه المعلومات من خادم يقوم بمحاكاة جهاز Mac ويرسل إليك بيانات "Anisette"؛ ولا يتم إرسال أي معلومات خاصة بالحساب إلى الخادم مطلقاً خلال هذه العملية.

عندما يستخدم العديد من الأشخاص نفس خادم Anisette (وتحديداً الإصدار الأول منه)، فإن ذلك يثيرأنظمة الحماية لدى Apple، مما يؤدي إلى قفل الحسابات التي كانت تستخدم ذلك الخادم. ولهذا السبب، أوصينا باستخدام حساب Apple منفصل ومؤقت بدلاً من حسابك الأساسي.

لقد عمل فريقنا على تطوير أساليب أفضل لتجنب قفل الحسابات (من خلال الأصدار الثالث من خادم الـ Anisette). ولكن، إذا كنت تستخدم إصداراً قديماً من SideStore، فإن استضافة خادم Anisette خاص بك تُعد وسيلة ممتازة لتجنب قفل الحسابات؛ إذ أصبحت هذه العملية سهلة للغاية بفضل كون خادمنا الحالي مفتوح المصدر ومُصمماً لبيئات Docker، مما يتيح لنا نشر الخادم بمجرد استخدام رابط GitHub.

## بث الخادم على Render

يعد [Render](https://render.com/) خدمةً تتيح إنشاء الخوادم بسهولة، وتدعم تحميل ملفات الخادم من GitHub مباشرة. ورغم أن الخطة المجانية لخدمة Render محدودة إلى حد ما، إلا أن الخادم يمكن أن يعمل عليها بسلاسة ودون أي مشاكل. (للعلم: تتطلب الخدمة بطاقة ائتمان للتحقق من الهوية، لكنها مجانية بالكامل).

نظراً لاستخدام عدد كبير جداً من الأشخاص لنفس رابط GitHub، سيتعين عليك إنشاء نسخة من الملفات من GitHub بنفسك.

1. [أنشئ حساب](https://github.com/signup) لـ GitHub، إذا لم يكن لديك حساب بالفعل.
2. [افتح](https://github.com/Dadoum/anisette-v3-server) صفحة ملفات الخادم على GitHub.
3. اضغط على "Fork" في الزاوية اليمنى العليا، وقم بعمل نسخة لملفات الخادم إلى حسابك.
4. بمجرد إنشاء نسخة من الملفات على حسابك، انقر على زر "Code" الأخضر الموجود في الزاوية العلوية اليمنى، وانسخ رابط .git.

* احفظ هذا لوقت لاحق.

بمجرد الانتهاء من ذلك، يمكن إنشاء الخادم على Render.

1. [أنشئ حساب](https://dashboard.render.com/register/) في Render.
2. أنشئ [New Web Service](https://dashboard.render.com/select-repo?type=web).
3. انتقل للأسفل إلى **Public Git repository** وأدخل الرابط الذي نسخته سابقاً.
4. انقر على "Continue" واملأ النموذج:
    * **الاسم** - لا يهم ماتضع هنا
    * **المنطقة** - اختر الأقرب إليك
    * **Branch** - main (الافتراضي)
    * **Root Directory** - دعه فارغاً (الافتراضي)
    * **Environment** - Docker (الافتراضي)
    * **Instance Type** - مجاناً

5. انتظر حتى يكتمل بناء الخادم. سترى ما يلي عند الانتهاء:

```
Machine requires provisioning... done !
Your service is live 🎉
```

*إذا فشلت عملية البناء لأي سبب، انقر فوق **Manual Deploy**، ثم **Deploy latest commit**.*

6. اعثر على رابط خادمك الجديد في أعلى الصفحة:

```
https://[اسم-الخادم-الخاص-بك].onrender.com
```

## إنشاء قائمة مخصصة لخوادم Anisette

بدءاً من الإصدار 0.5.8، يعتمد SideStore نظاماً لقائمة خوادم "anisette"، مما يسهّل إضافة الخوادم المعتمدة رسمياً. وهذا يعني أن الأمر يتطلب بعض الخطوات الإضافية إذا كنت ترغب في استخدام خادمك الخاص دون الحاجة لطلب إدراجه في القائمة الرسمية.

إذا كنت ترغب في الاحتفاظ بخيار استخدام الخوادم المضمنة، فاتبع الخطوات أدناه:
1. اذهب [هنا](https://servers.sidestore.io/servers.json) للحصول على قائمة الخوادم الحالية.
2. توجه إلى خدمة استضافة الملفات التي تريدها لاستضافة الملف على الإنترنت. نوصي باستخدام صفحة GitHub للقيام بذلك لأنه الأسهل في التعديل في المستقبل، وسيتم استخدامه كمثال لهذا الدليل. إذا كان لديك طريقتك الخاصة في الاستضافة، فقم بتكييف ما يلي مع الإعداد الخاص بك.
3. إذا كان لديك صفحة على GitHub بالفعل، فانتقل مباشرةً إلى الخطوة الفرعية السادسة. وإلا، فقم بما يلي:
* أنشئ صفحة GitHub جديدة باستخدام زر علامة الزائد (+) الموجود في الزاوية العلوية اليمنى في GitHub Desktop، أو عبر خيار New من القائمة الرئيسية، أو من خلال [هذه الصفحة](https://github.com/new).
* دع الأسم يكون [اسم المستخدم الخاص بك على GitHub].github.io، حدد خيار 'Initialize this repository with a README'، وقم بتعيين الإعدادات المتبقية كما تشاء.
* بمجرد الإنشاء، انتقل إلى Settings وانتقل إلى خيار Pages تحت قسم Code and automation.
* اضبط Build و deployment تحت Source إلى 'Deploy from branch'
* إذا لم يتم الاختيار بشكل تلقائي، اضبط Branch على 'main'.
* عُد إلى صفحة code (الصفحة التي يوجد فيها مربع اخضر بأسم Code)، واضغط على "Add files" ثم "Upload files"، وبعد ذلك اختر ملف "servers.json" الذي قمت بتنزيله مسبقاً.
* بمجرد تحميل الملف، انقر عليه واضغط على زر "الذي يحمل شكل قلم" لتعديل الملف.
* انتقل للأسفل إلى الخادم الأخير في القائمة وأضف فاصلة بعد القوس المتعرج ('}') الخاص بذلك الخادم، ثم أضف الخادم الخاص بك بعده بالتنسيق التالي:
```
{
    "name": "[شيء يمكن التعرف عليه، مثل اسم المستخدم. يجب أن يكون بالغة الأنجليزية]",   //لا يهم حقاً ما تسميه، ما لم تكن تشارك قائمة الخوادم هذه مع شخص آخر.
    "address": "[رابط الخادم الخاص بك]"
}
```
* اضغط على Commit changes، ثم انتقل إلى https://[اسم المستخدم الخاص بك على GitHub].github.io/[المكان الذي وضعت فيه الملف]/servers.json. إذا تم تحميل الملف، فأنت جاهز للانتقال إلى القسم التالي. أما إذا لم يحدث ذلك، فقد تحتاج إلى الانتظار لمدة تصل إلى 10 دقائق حتى يتم إعداد موقعك بشكل صحيح للاستخدام قبل المحاولة مرة أخرى.

إذا كنت ترغب في استخدام خادمك الخاص فقط، فاتبع الخطوات المذكورة أعلاه، ولكن بدلاً من نسخ ملف servers.json الرسمي، قم بإنشاء ملفك الخاص باستخدام هذا التنسيق.:
```
{
    "servers": [
        {
            "name": "[كما ورد أعلاه]",
            "address": "[كما ورد أعلاه ايضاً]"
        }
    ]
}
```
وواصل العمل كالمعتاد.

## استخدام خادمك مع SideStore

لاستخدام قائمة الخوادم التي أنشأتها حديثاً في تطبيق SideStore، قم بما يلي:

1. افتح Settings في SideStore..
2. اسحب الشاشة للأسفل واضغط على 'Anisette Servers'.
3. اضغط على رابط القائمة واستبدله برابط قائمة الخادم الخاص بك..
4. اضغط على 'Refresh Servers'، واختر خادمك من القائمة المحدثة.
