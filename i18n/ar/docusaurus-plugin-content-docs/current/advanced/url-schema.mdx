# مخطط الرابط

فيما يلي قائمة بمختلف مخططات العناوين (URLs) التي يمكن استخدامها للتفاعل مع SideStore. وتُعد هذه المخططات مفيدة للغاية؛ إذ تتيح للمطورين ببساطة وضع رابط يُفعَّل بنقرة واحدة على وسائل التواصل الاجتماعي أو مواقعهم الإلكترونية، ليقوم نظام iOS بفتح الرابط مباشرةً داخل SideStore وتنفيذ الإجراء (أو الإجراءات) المحدد.

تقتصر الروابط في الوقت الحالي على تثبيت التطبيقات و إضافة المصادر، ولكن سيتم توسيع نطاقها مستقبلاً لتتيح قبول مدخلات متعددة وتنفيذ مجموعة متنوعة من المهام الأخرى.

## تثبيت تطبيق مستضاف عن بُعد

```
sidestore://رابط التحميل]=رابط?التثبيت]
```

## أضافة مصدر من AltSource

```
sidestore://رابط المصدر]=رابط?المصدر]

```
