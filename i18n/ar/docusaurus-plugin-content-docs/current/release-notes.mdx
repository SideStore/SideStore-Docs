# ملاحظات الإصدار المستقر (Stable)

## 0.6.2

### سجل التغييرات
- إيقاف دعم WireGuard، والانتقال الكامل إلى [StosVPN](https://apps.apple.com/us/app/stosvpn/id6744003051)
- دمج المزيد من AltStore 2.0
- تمت إضافة دعم لاستيراد وتصدير ترخيص Apple ID لاستخدامها عبر أجهزة متعددة، بالإضافة إلى تعليمات حول كيفية القيام بذلك [هنا](https://github.com/SideStore/SideStore/pull/1008#issue-3138680291)
- يضيف مخطط الرابط / يتيح تصدير الترخيص (إلى LiveContainer)
- إصلاح مشكلة توقف تثبيت التطبيقات عند نسبة 75% تقريباً
- إضافة خيار لإعادة استخدام ملف تعريف الـ App ID الرئيسي للإضافات بدلاً من إزالتها وتسجيلها (معرف تطبيق واحد لكل تطبيق).
- إصلاحات عامة وتحديثات مرئية
